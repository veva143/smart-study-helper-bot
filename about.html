About the project

BCA Summer Training Project 2026, done during the internship at Webmeen.

🎓

Project

Smart Study Helper Bot, a web-based study assistant. Student: Vaibhav Verma. Guide: Dr. Arti Bajaj.

🛠️

Technology

HTML, CSS and JavaScript on the front end. Cloudflare Pages for hosting. An online AI model for answers.

🔎

NLP inside

Tokenization, stop-word removal, stemming, TF-IDF, cosine similarity and edit-distance spelling correction.

🧠

Quiz engine

Over a thousand questions are generated from the notes. Every attempt is new and options are shuffled.

🤖

Assistant

Online AI first. If it is not available, the offline NLP search of the library answers, so the bot never stops.

✅

Tested

Unit, integration, black-box, system and compatibility testing, plus Lighthouse checks.
